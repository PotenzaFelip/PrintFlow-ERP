# 🚀 PrintFlow ERP - Gestão Inteligente para Impressão 3D

O **PrintFlow ERP** é uma solução completa em Python projetada para pequenos e médios produtores do ecossistema de manufatura aditiva. Diferente de calculadoras comuns, o sistema integra o controle de estoque de filamentos, a produção de peças e a frente de caixa (vendas), gerando insights automáticos através de Dashboards estatísticos.



## ✨ Funcionalidades Principais

- **📦 Gestão de Insumos:** Controle de estoque de filamentos com preço por grama e rastreabilidade por ID.
- **⚙️ Produção & Orçamentos:** Calculadora técnica que considera peso, tempo de impressão, hora-máquina e margem de lucro.
- **📉 Rastreabilidade Total:** Vínculo direto entre o lote do filamento utilizado e a peça produzida.
- **💰 Frente de Caixa:** Registro de vendas com baixa automática de estoque e atualização de valor patrimonial.
- **📊 Dashboard com Pandas:** Visualização gráfica de faturamento, distribuição de materiais e ranking de produtos mais lucrativos.

## 🛠️ Tecnologias Utilizadas

- **Python 3.10+**
- **CustomTkinter:** Interface moderna e responsiva em Dark Mode.
- **Pandas:** Processamento e manipulação de dados financeiros.
- **Matplotlib:** Geração de gráficos estatísticos integrados.
- **SQLite:** Banco de dados relacional leve e robusto.
